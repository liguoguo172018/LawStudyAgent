# 来源管理：核验、引用、冲突与版权

本文件展开 SKILL.md §10。目标是让每一条法律知识都能回答三个问题：**谁说的、能证明什么、现在还有效吗。**

## 1. 来源类型与证明任务

| 类型 | 能证明 | 不能证明 | 典型材料 |
| --- | --- | --- | --- |
| 权威规范 | 现行效力、规范内容、官方立场 | 学理争议、个案裁判结果 | 法律、行政法规、地方性法规、司法解释、官方答复 |
| 课程资料 | 本课程教什么、课程口径、考试范围 | 现行法是否如此、学界通说 | 教师课件、指定教材、课堂笔记、课程大纲 |
| 专业教学资料 | 学科体系与通说 | 具体条文的现行版本 | 通行教材、课程讲义 |
| 学术研究 | 学理观点与论证 | 现行法效力、裁判结论 | 论文、专著、评论 |
| 实践资料 | 规范在个案中的适用 | 一般规则本身 | 裁判文书、指导性案例、典型案例 |
| 学习者观点 | 用户当前理解 | 知识正确性 | 用户笔记、口述 |
| AI 推论 | 辅助推理与归纳 | 事实与权威结论 | 模型生成的总结、类比、推导 |

**不同来源承担不同证明任务，不做一个总排名。** 判断现行法效力时，权威规范优先；判断“本课程考什么”时，课程资料优先；判断“学界怎么争论”时，学术资料优先。

## 2. 引用格式

### 法律法规

```text
《中华人民共和国民法典》第 509 条（2020-05-28 通过，2021-01-01 施行）
```

要求：

- 法规全称，不使用简称首次出现。
- 条款序号准确；不确定条号时写“合同编关于履行的规定（具体条号待核验）”，**不得编造条号**。
- 注明版本：通过日期、施行日期；有修正的注明修正时间。
- 引用原文时加引号，并注明“原文”；转述不加引号，但注明“转述”。

### 裁判文书

```text
（示例，虚构）(20XX) 最高法民终 XXX 号民事判决书，最高人民法院，20XX-XX-XX，
来源：中国裁判文书网（示例，非真实检索记录）
```

要求：案号、法院、裁判日期、来源齐全；无法核实的案号不得使用；不得把虚构案例写成真实案例。以上案号、日期和来源均为占位示例，不是真实案件。

### 教材与专著

```text
作者：《书名》，出版社，第 X 版，出版年，第 XX 页。
```

页码必须真实可查；只看过目录或二手转述时，注明“转引自”并给二级来源。

### 课程资料

```text
课程资料：<课程名>，<文件名>，第 X 页 / 第 X 讲（教师课件，版权归原权利人）
```

### 网络资料

```text
页面标题，站点名，URL（检索日期 YYYY-MM-DD）
```

优先引用官方或机构来源；个人博客、问答平台只作线索，不作权威依据。

## 3. 核验流程

### 3.1 现行法条文

1. 确认法规名称与制定机关。
2. 到权威来源查条文：国家法律法规数据库、最高人民法院/最高人民检察院官网、国务院公报等。
3. 核对三件事：**条文内容、现行版本、生效时间**。
4. 检查是否有修正、废止或过渡规定（新旧法衔接）。
5. 记录检索日期；法律会变，核验结果有保质期。
6. 在知识点或回答中标注 `[已核验]` 并给出来源。

无法访问权威来源时：标 `[待验证]`，说明“需核对现行条文”，不得凭记忆写条号。

### 3.2 案例

1. 确认案号格式与法院层级。
2. 到裁判文书网或官方案例库核对当事人、案由、裁判日期、裁判要点。
3. 区分“裁判要旨”与“本院认为”的原文，不把学理评论写成裁判观点。
4. 指导性案例注明批次与编号。
5. 无法核实的案例只能作为“教学示例（虚构）”。

### 3.3 教材与课程资料

1. 核对书名、版次、页码。
2. 区分教材作者观点与教材转述的通说。
3. 课程课件与教材不一致时，以课程要求为准回答“本课程口径”，同时标注教材/现行法的不同表述。

### 3.4 AI 生成内容

模型生成的总结、类比、例子默认 `[推断]`；涉及条文、案号、数字、期限的，必须核验后才能改为 `[已核验]`。不得把“模型记得”当作来源。

## 4. 认知标签

| 标签 | 含义 | 使用条件 |
| --- | --- | --- |
| `[已核验]` | 已对照权威来源确认 | 记录来源、版本、检索日期 |
| `[推断]` | 基于已知信息的合理推理 | 说明推理依据与不确定性 |
| `[待验证]` | 尚未核实或存在疑点 | 说明需要查什么、去哪里查 |

使用规则：

- 一条判断只能有一个主认知标签，不用“基本已核验”这类模糊说法。
- 标签放在判断句末尾或段落开头，全文一致。
- 用户提供的观点标 `[用户观点]`，不因用户坚持而升级为已核验。
- 多来源冲突时，每个来源各自标标签。

辅助标记（不替代认知状态标签）：

| 标记 | 类别 | 含义 | 使用条件 |
| --- | --- | --- | --- |
| `[用户观点]` | 来源属性 | 该判断来自用户的理解或表述 | 与来源对照后再判断；不得因用户坚持而升级 |
| `[待复核]` | 冲突状态 | 来源冲突或证据不足，暂不结论 | 记录冲突双方、待查事项与复核期限 |

## 5. 冲突处理

### 5.1 冲突类型

| 类型 | 例子 | 处理重点 |
| --- | --- | --- |
| 版本差异 | 旧教材引用已修正条文 | 以现行版本为准，旧版仅作历史说明 |
| 层次差异 | 教材讲一般规则，司法解释给特别规则 | 分别说明适用层次，不互相否定 |
| 学理分歧 | 构成要件说 vs 法律效果说 | 并列呈现，注明作者与理由 |
| 课程口径差异 | 教师采甲说，通说采乙说 | 标明“本课程口径”，考试按课程口径，同时提示差异 |
| 事实错误 | 来源本身写错条号或案号 | 指出错误，给出正确来源，不沿用 |
| 时效差异 | 新旧法交替期 | 说明时间效力与衔接规则 |

### 5.2 处理步骤

1. **保留原文**：记录双方的原话、出处、页码/条号，不先改写。
2. **定位差异**：是版本、层次、学说还是表述问题。
3. **判断影响**：是否改变结论；不改变则说明“表述差异，不影响结论”。
4. **给出处理**：以哪一方为主、另一方在什么条件下适用。
5. **标记状态**：无法判断时标 `[待复核]`，写入疑问清单。
6. **报告用户**：说明冲突点、影响、建议核验路径；不擅自替用户选边。

### 5.3 禁止

- 把两种学说融合成一段“通说”。
- 用旧教材否定现行法，或用现行法否定课程要求。
- 只保留一个来源、删掉另一个来源的记录。
- 仅凭文件修改时间判断哪个正确。

## 6. 不确定性与错误处理

- 不确定条号：写“相关条文（条号待核验）”，不写“第 X 条”。
- 不确定页码：写“参见该章”，不编页码。
- 发现之前回答有错：明确更正，说明错在哪里、依据是什么；保留原记录并追加更正，不静默修改历史。
- 用户指出错误且证据充分：接受并更新；证据不足：标“待复核”，不因压力改口。
- 无法回答：说明缺什么资料、需要查什么，给可执行的核验路径。

## 7. 版权与资料边界

### 允许

- 用自己的话总结教材观点，并注明出处。
- 短引用：为说明或评论目的引用必要段落，加引号并注明出处。
- 使用公开的法律法规、司法解释、裁判文书（遵守其使用规则）。
- 使用自己编写的示例、类比、题目。

### 不允许

- 大段复制教材、课件、讲义、试卷、辅导书内容。
- 把教师课件、付费课程资料上传到公开仓库或公共课程模块。
- 扫描整本书并分发。
- 使用未授权的题库、答案、内部讲义。
- 把“网上找到的”内容当作可自由使用的材料。

### 公开项目的额外要求

- 课程模块只放**结构、公开资料索引、原创说明**，不放受版权保护的原文。
- 每个课程模块注明教材版本与资料来源；无法确认授权时，只写书目信息，不贴内容。
- 示例课程使用原创内容，并明确标注“教学示例（虚构）”。
- 用户个人资料、学习记录、薄弱点档案永不进入公开仓库。

## 8. 来源记录的最小字段

任何进入知识条目或回答的来源，至少记录：

```yaml
type: 权威规范 | 课程资料 | 专业教学资料 | 学术研究 | 实践资料 | 学习者观点 | AI推论
cite: 可定位的引用（名称 + 条款/页码/案号）
version: 版本或日期（法规施行日期、教材版次、检索日期）
status: 已核验 | 推断 | 待验证 | 待复核
supports: 该来源支持本条目的哪一部分
limits: 该来源不能证明什么
```

`limits` 常被忽略，但它决定回答的边界：课件能证明“课上这么讲”，不能证明“现行法如此”。
