# 示例课程：法理学导论（虚构）

> **版权与真实性说明**
> 本示例课程为**原创教学示例（虚构）**：课程名称、教材信息、章节编号、题目与学习者作答均为编写者虚构，不对应任何学校、教师或教材。
> 其中的法理学概念按通行理解自行表述，**未引用任何教材原文**；正式学习请以你所在课程的指定教材与教师口径为准。
> 本文件用于演示 LawStudyAgent 的工作流程，不是真实学习记录，也不构成法律意见。

---

## 0. 场景设定

- 学习者：大二法学生“小林”（虚构）。
- 课程：法理学导论，自学，每周 3 小时。
- 目标：能区分法律规则、法律原则、法律概念，并能在短案例中判断适用顺序。
- 可用资料：只有一份自拟的课程大纲（虚构），没有教材电子版。

> **时间线**：本示例只包含一次学习会话（2026-11-10）和一次计划中的复测（2026-11-13）；没有发生第二次学习，也没有已完成的复测结果。

这组设定刻意模拟“资料不全、以理解为主”的常见情况：Agent 需要标注资料缺口，而不是编造教材内容。

```markdown
## 核心内容
法律规则是规定具体权利义务内容及相应法律后果的规范。它的特点是把行为模式与后果
相对明确地对应起来，便于直接适用。

## 要素与要件
| 要素 | 含义 | 判断提示 |
| --- | --- | --- |
| 假定条件 | 规则适用的情境或主体条件 | 题干事实是否落在此情境 |
| 行为模式 | 允许、要求或禁止的行为 | 是授权、义务还是禁止 |
| 法律后果 | 符合或违反模式后的结果 | 是否产生肯定或否定的后果 |

## 辨析
| 对比项 | 法律规则 | 法律原则 |
| --- | --- | --- |
| 内容具体程度 | 较具体，有行为模式与后果 | 较抽象，多为价值指引 |
| 适用方式 | 要件满足即适用（涵摄） | 衡量、权衡，通常在有规则时退居其次 |

## 例证
- 正例（虚构）：某校《图书馆借阅规则》规定“逾期每册每日记 0.5 分”，有明确条件、
  行为与后果，结构上类似法律规则。
- 反例（虚构）：某章程写“应当诚实守信”，未给出具体行为模式与后果，更像原则。
- 边界例：条文中出现“情节严重”等评价性表述，仍可能是规则，只是需要解释。

## 常见错误
- 看到“应当”就认定为义务性规则（“应当”也可能出现在原则性宣示中）。
- 把规则的三个要素当成三个独立条文。

## 检测问题
1. 给一段规范文本，指出假定条件、行为模式、法律后果分别是什么。
2. 该规范属于授权性规则还是义务性规则？依据是什么？

## 证据记录
| 日期 | 层次 | 题目/任务 | 表现 | 结论 |
| --- | --- | --- | --- | --- |
| 2026-11-10 | 记忆 | 口述规则三要素 | 三要素齐全 | 通过（8/8） |
| 2026-11-10 | 辨析 | 判断文本是规则还是原则 | 以“应当”为标准，未说明具体化程度与后果 | 未通过（4/8） |
```

### 2.2 `01-02-法律原则.md`（摘要）

- 核心：为规则提供基础与指引的综合性准则，通常不预设具体事实状态与后果。
- 关键辨析：有规则时优先适用规则；适用原则需要更强理由，并说明衡量过程。
- 掌握状态（课后快照）：记忆“未测试”，理解“未测试”，辨析“待复测”（第 2 题 4/8），应用“待复测”（第 3 题 3/8）。
- 来源状态：`待验证`（无指定教材，表述为一般理解）。

### 2.3 `01-03-法律概念.md`（摘要）

- 核心：对法律事实的共同特征作抽象概括，如“法人”“善意”“要约”。
- 功能：降低规范表述成本，使规则可以一般化适用。
- 与规则、原则的关系：概念是构成规则与原则的“材料”，本身通常不直接产生法律后果。
- 掌握状态：全部“未测试”。

## 4. 这个示例演示了什么

| 步骤 | 示例中的体现 |
| --- | --- |
| 资料接收 | 只有自拟大纲，教材缺口被明确记录，未编造教材内容 |
| 知识体系 | 三个原子化条目，规则与原则建立“对照”关系 |
| 概念讲解 | 定义 → 要素 → 对照 → 正例/反例/边界例 → 检测问题 |
| 案例与辨析 | 用虚构短案例测“原则能否优先适用” |
| 诊断 | 先答后评、四项评分、区分概念混淆与原理不清 |
| 薄弱点 | 同一知识点在第 2、3 题连续失败，达到“重复出错”门槛后才登记；附两道题的证据与复测计划 |
| 掌握状态 | 只更新有证据的层次：demo-01-01 记忆（第 1 题）与辨析（第 2 题）、demo-01-02 辨析（第 2 题）与应用（第 3 题）；未测层次保持未测试 |
| 层次边界 | 应用失败只更新应用层，不用应用题反推或改写理解层状态 |
| 复习 | 按错误类型排题，3 天后复测，换新案例 |
| 来源 | 教材缺失标“待验证”，不把一般理解写成教材原文 |

## 5. 复用到自己的课程

1. 复制本文件的**结构**，不要复制具体法理学内容。
2. 把“法理学导论”换成你的课程，教材信息填真实版本。
3. 先建 3–5 个知识点跑通流程，再批量扩展。
4. 第一次诊断只测 3 题，确认评分与记录方式适合你，再增加题量。

> 提醒：示例中的法理学表述经过简化，仅用于演示流程；考试作答请以指定教材和教师讲解为准。
